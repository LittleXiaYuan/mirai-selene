# Mirai-Selene · 项目立意与叙事

## 一句话

> **预测万物，不如走进一个世界。**

Mirai-Selene 是一个“可拥有的平行世界引擎”。输入一段现实，生成一片可以走进去、可以分支、可以带走、可以负责的平行世界。

## 四拍叙事

1. **过去，预测是一份报告。**
   一份图表、一个结论、一个“专家说”。
2. **MiroFish 把预测变成沙盘。**
   群体智能、平行数字世界、预测万物。你可以在外面看它跑。
3. **但沙盘还是沙盘。**
   你只能看，不能走进去；只能相信，不能回滚；只能得到一个未来，不能拥有它的分支。
4. **Mirai-Selene 把沙盘变成世界。**
   世界模型学动态，状态代数给控制权，视觉小说给体验，世界文件给所有权。

> **MiroFish 把预测变成沙盘；我们把沙盘变成世界。**

## 三层立意

### 1. 选择权（对个人）

林夏的故事不是“哪条路对”，而是“我有没有选择权”。

产品不替她选，也不替用户选。它把三条世界线摊开：去上海、留校读研、回青岛。你可以走进去、比较、合并、回滚。**不是给你一个答案，是给你选择的条件。**

### 2. 所有权（对创作者）

世界不是平台的黑盒，是一个 `.world` 文件。

创作者可以导出、迁移、交易；观众的分支可以带走；角色、记忆、路线、审计都在文件里。**创作者造世界，观众走进去，世界归创造它的人。**

### 3. 可负责性（对 AI）

AI 世界要可信，先要可治理。

每个状态变化都有审计；记忆可以删除、回滚、证明删干净；合并冲突会拒绝，不瞎平均。**我们不是在造一个更聪明的 AI，我们在造一个可以负责的世界。**

## 产品形态

- **Studio**：作者的工作台。导入内容、捏角色、预测事件。
- **Stage**：观众的视觉小说。走进去、做选择、晚安、合并。
- **World File**：资产。状态 + 历史 + 权限 + 审计。

> **Studio 造世界，Stage 走进去，World File 是资产。**

## MiroFish vs Mirai-Selene

| | MiroFish | Mirai-Selene |
|---|---|---|
| 输入 | 种子信息、新闻、报告 | 一段现实、角色、故事 |
| 世界 | 一个平行数字世界 | 多个可分支的世界 |
| 智能体 | LLM agents + GraphRAG | 学习型世界模型 + 推演引擎 |
| 输出 | 预测报告 + 可对话世界 | 可走进去的 VN + 可带走的 `.world` |
| 状态 | 图记忆、日志 | 显式状态，可分支/合并/回滚/审计 |
| 用户的动作 | 看、问、读报告 | 走进去、做选择、合并、回滚、带走 |
| 一句话 | 预测一个未来 | 拥有很多个 |

## “预测万物”可以推演什么

- 一段**校园**：如果她去了上海 / 如果学校改了政策
- 一家**公司**：如果裁员 / 如果换 CEO
- 一个**家庭**：如果母亲先说“你去吧”
- 一段**历史**：如果当时没有签那份条约
- 一个**故事**：如果林夏没有接那个电话
- 一个**人生**：考研 / 工作 / 回青岛

> **任何有角色的系统，都可以被推演。**
